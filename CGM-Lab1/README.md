# Computer Graphics Lab – Assignment 1
## Basic Graphics Primitives Using C++

### 📌 Objective
To write a C++ program using the `graphics.h` library to draw four basic graphics primitives in a single graphics window:

1. Straight Line
2. Circle
3. Rectangle
4. Triangle

---

### 🛠️ Technologies Used

- **Programming Language:** C++
- **Graphics Library:** graphics.h (WinBGIm)
- **Header File:** conio.h
- **Compiler:** GCC / MinGW
- **IDE:** Visual Studio Code

---

### 📖 Graphics Primitives Explained

**1. Straight Line**

A straight line is drawn between two specified coordinate points using the `line()` function.

**2. Circle**

A circle is drawn using the `circle()` function by specifying its center coordinates and radius.

**3. Rectangle**

A rectangle is created using the `rectangle()` function by specifying its top-left and bottom-right coordinates.

**4. Triangle**

A triangle is created by connecting three straight lines using the `line()` function.

---

### ⚙️ Functions Used

| Function | Description |
|---|---|
| `initgraph()` | Initializes the graphics mode. |
| `line()` | Draws a straight line between two points. |
| `circle()` | Draws a circle with a specified center and radius. |
| `rectangle()` | Draws a rectangle using two corner coordinates. |
| `getch()` | Waits for a key press. |
| `closegraph()` | Closes the graphics mode. |

---

### 📚 Header Files Used

- **`graphics.h`** – Provides graphics functions for drawing geometric shapes.
- **`conio.h`** – Provides the `getch()` function to pause program execution until a key is pressed.

---

### 🖥️ Expected Output

The program displays all four graphics primitives in a single graphics window:

- Straight Line
- Circle
- Rectangle
- Triangle
