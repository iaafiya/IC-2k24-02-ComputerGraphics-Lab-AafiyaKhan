### Theory: DDA Line Drawing Algorithm

The **Digital Differential Analyzer (DDA)** is a line drawing algorithm used in computer graphics to generate a straight line between two given endpoints.

It calculates intermediate points between the starting and ending coordinates using incremental calculations.

### Algorithm

1. Start the program.
2. Initialize the graphics mode using `initgraph()`.
3. Input the starting point `(x1, y1)` and ending point `(x2, y2)`.
4. Calculate the differences:
   - `dx = x2 - x1`
   - `dy = y2 - y1`
5. Calculate the number of steps:

   `steps = max(abs(dx), abs(dy))`

6. Calculate the increments:

   - `x_increment = dx / steps`
   - `y_increment = dy / steps`

7. Initialize `x = x1` and `y = y1`.
8. Use a loop to calculate and plot intermediate points using `putpixel()`.
9. Use `round()` to convert floating-point coordinates into integer pixel positions.
10. Display the completion message.
11. Close the graphics window using `closegraph()`.

**Special Case:** If both endpoints are identical (`steps == 0`), the program plots a single pixel instead of performing incremental calculations.
