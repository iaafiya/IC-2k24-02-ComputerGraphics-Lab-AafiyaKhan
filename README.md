## About the Repository

This repository contains the practical programs, assignments, and lab activities completed as part of the **Computer Graphics and Multimedia (CGM) Lab** course.

It covers fundamental concepts and practical implementations of computer graphics, including:

- Basic Graphics Shapes and Primitives
- Line Drawing Algorithms (DDA, etc.)
- Circle Drawing Algorithms
- 2D Transformations
- Polygon Operations
- Clipping Algorithms
- Other Computer Graphics Techniques

## How to Run the Programs

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the required lab folder in Visual Studio Code.

3. Compile the C++ program with the required graphics library configuration.

4. Run the generated executable file.
